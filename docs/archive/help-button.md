# Help Button Checklist

- [x] Task A — `game/help_tile.lua` — Create the HelpTile world-space interactable. Mirror the structure of `wall_view_tile.lua`: invisible footprint `Sprite`, `:interact()` that calls `on_press`, `:centre()`, and `:draw()` that renders a magenta square (use colour `(0.9, 0.2, 0.9, 1)` when `self.active == false`, `(1, 0.5, 1, 1)` when `self.active == true`). Expose `self.active = false` so callers can set it.

- [x] Task B — `game/scenes/game_scene.lua` — Wire HelpTile into `GameScene:on_enter()`: require `HelpTile`, construct `self.help_tile = HelpTile.new(0, WORLD_H - C.SLOT, function() self:_toggle_help() end)`, add to drawer at `C.PRIORITY_PIECE`, set `self.help_mode = false`. Add `GameScene:_toggle_help()` that flips `self.help_mode` and sets `self.help_tile.active`.

- [x] Task C — `game/scenes/game_scene.lua` — Add `GameScene:_draw_help_overlay()`. For each piece in `self.pieces` plus `self.player.held_piece` (if non-nil), compute `correct` and `incorrect` neighbor counts: iterate all same-`path` pieces and check if they are exactly 1 SLOT away in world space; if so, test the "same rotated origin" condition (see design doc). Draw `love.graphics.rectangle("fill", piece.sprite.x, piece.sprite.y, C.SLOT, C.SLOT)` tinted green `(0.2, 0.9, 0.2, 0.45)` when `correct >= 1 and incorrect == 0`, or red `(0.9, 0.2, 0.2, 0.45)` when `incorrect >= 1`. No overlay when both counts are 0.

- [x] Task D — `game/scenes/game_scene.lua` — Call `_draw_help_overlay` from `GameScene:draw()` when `self.help_mode` is true. For single-player: after `Scene.draw(self)`, re-enter camera transforms (`self.camera:attach()` / `self:_draw_help_overlay()` / `self.camera:detach()`). For 2P: do the same within each scissored camera block after `self.drawer:draw()`.

- [x] Task E — `game/scenes/game_scene.lua` — Include `self.help_tile` in the `_spawn_box` occupancy check (alongside the existing `self.wall_tile` check). Also update the HUD hint string in `draw()` to add `  H: help` (or `E: help ↙`) to the existing controls line.

- [x] Task F — `game/scenes/game_scene.lua` — Pass `self.help_tile` into `self.player:update(...)` in `GameScene:update()` so the player can interact with it the same way as `wall_tile`. Mirror the existing `wall_tile ~= nil` interaction block in `player.lua` — but since `player.lua` already handles any object with `:centre()` and `:interact()` for the `wall_tile`, wire the help tile as a second interactable via the same E-key proximity logic. Add a second `wall_tile`-style check block in `player.lua` for `help_tile`, OR (simpler and preferred) make `GameScene:update()` manually check proximity and call `self.help_tile:interact()` itself after `self.player:update()`, mirroring how pile interactions are handled directly in the scene — whichever is simpler. Use the simpler approach: handle it in `game_scene.lua` by checking `self.player`'s proximity to `self.help_tile:centre()` and calling `interact()` on E-press, without modifying `player.lua`.
